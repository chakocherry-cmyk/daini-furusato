# 第二のふるさと

旅先で会った人から次の体験が届き、もう一度訪れたくなる観光客向けのWebアプリです。

データはこのブラウザの中だけに保存します。ログイン、決済、外部APIはありません。

## 必要なもの

- Node.js 24 系
- npm 11 系
- Chrome または Edge

## 起動方法

プロジェクトフォルダで、次を実行します。

```bash
npm install
npm run dev
```

ブラウザで次のURLを開きます。

http://127.0.0.1:5173/

スマホ幅で見るときは、ブラウザの幅を 390px 前後にしてください。

## デモの操作

1. 「郷土料理を教わりたい」を選ぶ
2. 「おばぁと作る家庭料理」を開く
3. 「参加済みにする」
4. 「第二のふるさとに登録する」
5. 下の「ふるさと」で、沖縄本島のアルバムカードを確認する
6. 上の「3か月進める」
7. 「おかえり」で、見出し「また一緒に料理を作ろうね」と「今度は沖縄そばを一緒に作ろうね」を確認する
8. 「また会いに行きたい」を押し、「ふるさと」のアルバムで再訪希望が「登録済み」になることを確認する

最初の状態に戻すときは「デモを最初から」を押します。参加履歴、ふるさと登録、デモ時間、招待状、再訪希望が消えます。

参加前でも、第二のふるさとに登録した地域は「ふるさと」の一覧に出ます。招待状までの月数は体験ごとに違い、家庭料理と秋祭りは3か月、収穫・海辺・朝市は2か月です。料理体験の大きな写真と招待状の文章は、画面ではなく `src/data.js` の体験データにあります。
